## 翻译约定 / Translation Conventions

### 保留原样的内容 / Preserve As-Is
以下内容在翻译时应保持原样：
- 代码块和命令 / Code blocks and commands
- 文件路径 / File paths
- URL 链接 / URLs
- 命令输出 / Command output
- 寄存器转储 / Register dumps
- 堆栈跟踪 / Stack traces

### 翻译的内容 / Translate
以下内容应翻译：
- 标题和章节名 / Headings and section names
- 说明文字和描述 / Explanatory text and descriptions
- 步骤说明 / Step instructions
