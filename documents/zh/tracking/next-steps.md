- **仅使用 GitHub Releases**（目前）。

- 基础虚拟机包含 **LLDB + GDB**。
- 基础虚拟机**不**包含 SOS。
- SOS 在 **.NET 调试包**（可选下载）中提供。
- 分发渠道：**仅 GitHub Releases**。
